Рівняння по кроках
Рівняння (відповідь)
x + a = b
Невідомий доданок
Щоб знайти невідомий доданок, від суми віднімаємо відомий доданок.
x + 17 = 45
x = 45 − 17
x = 28
x − a = b
Невідоме зменшуване
Щоб знайти невідоме зменшуване, до різниці додаємо від’ємник.
x − 14 = 30
x = 30 + 14
x = 44
a − x = b
Невідомий від’ємник
Щоб знайти невідомий від’ємник, від зменшуваного віднімаємо різницю.
80 − x = 35
x = 80 − 35
x = 45
x · a = b
Невідомий множник
Щоб знайти невідомий множник, добуток ділимо на відомий множник.
x · 6 = 48
x = 48 : 6
x = 8
x : a = b
Невідоме ділене
Щоб знайти невідоме ділене, частку множимо на дільник.
x : 4 = 9
x = 9 · 4
x = 36
a : x = b
Невідомий дільник
Щоб знайти невідомий дільник, ділене ділимо на частку.
63 : x = 7
x = 63 : 7
x = 9
x + 17 = 60 − 8
Складені рівняння
Спочатку обчисли вираз праворуч (окремо) і перепиши рівняння, потім застосуй потрібне правило.
x + 17 = 60 − 8
x + 17 = 52
x = 52 − 17
x = 35Окремо: 60 − 8 = 52
